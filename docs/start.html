That's it - what happens now

A robot in the cloud checks the card shops around the clock and pings you the moment a new One Piece or Pokemon listing shows up (official Bandai, Premium Bandai, LA Sports Cards, Hot Topic, BoxLunch, Newegg, Macy's). Your phone and computer can be off; the ping still arrives.

Restocks sell out fast, so treat a ping as "go buy it now". You'll get one ping per new item, not a ping every check.

Want to see what's being watched and when it was last checked? Open the status page. Viewing needs no login.

Nothing new has launched yet since the watcher started, so it's normal to have received no pings so far. The test button above is how you confirm the pipe works.
